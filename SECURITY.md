# Security Policy

## Supported versions

FastDDD Tooling is currently in the 1.0 pre-release line. No public GA version is supported yet. Supported release lines and end-of-support dates will be published with the first stable release.

## Reporting a vulnerability

Do not disclose suspected vulnerabilities, unsafe generated output, template injection, path traversal, or credential exposure in public issues.

Send a private report to `39100782@qq.com` with the subject `[FastDDD Tooling Security]`. Include the affected artifact/version, generation inputs with secrets removed, reproduction steps, impact, and any proposed mitigation.

The maintainer will acknowledge receipt and coordinate validation and disclosure. Formal response and remediation SLAs will be defined before the first public stable release.
